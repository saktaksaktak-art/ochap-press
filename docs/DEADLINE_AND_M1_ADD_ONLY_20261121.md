## 追加機能
- 当日のお気に入り場：日本時間（Asia/Tokyo）の公式締切時刻と現在時刻を照合。未締切レースを締切昇順に表示。既に締切済みのレースは初期非表示、「締切済みも表示」で未締切の後ろに表示。ページ復帰時と30秒ごとに更新。
- `deadline.html`：全場の既存M0予想を公式締切順で一覧表示。既存データ `data/consensus/YYYY-MM-DD.json` を読む専用の追加ページ。過去号は全件、当日は未締切を初期表示。
- `m1.html`：M1専用の独立ページ。原本SHA、締切前凍結時刻、艇番/登録番号一致、真正な保存記録を別途検収した `ochap.public.m1.v1` JSON だけを正式掲載。データ未掲載なら明確に未掲載とし、凍結していないチャット予想を後付けで正式M1として採用しない。現状、配信原本の生成・保存経路は未接続。
- モバイル390px・PC1280pxのE2Eおよび既存紙面/過去号/320px表示の回帰を別CIで検査する。
