# 公開新聞の編集方針

公開紙面はレース・選手・データ・印・展開・買い目・予想理由を中心にする。

保存時刻、凍結レシート、SHA、Drive/GitHubへの受け渡し、内部認定・BC採否、検収経緯、担当間の連絡は共通台帳・出典メタデータで保持し、紙面に繰り返し掲載しない。内部情報を削ったことを正式認定・BC対象への昇格と扱わない。

読者が数値や図を理解するための説明は、簡潔な「紙面の見方」一か所にまとめる。欠測や予想未掲載など、そのレースを読むうえで必要な状態は短く明示する。記者名を各見出しで繰り返さない。

表現整理で凍結原稿・予想JSON・印・買い目・根拠・数値を変更しない。旧号の無差別書換えはしない。
