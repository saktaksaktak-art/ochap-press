# 公開新聞の編集方針

公開紙面はレース・選手・データ・印・展開・買い目・予想理由を中心にする。

保存時刻、凍結レシート、SHA、Drive/GitHubへの受け渡し、内部認定・BC採否、検収経緯、担当間の連絡は共通台帳・出典メタデータで保持し、紙面に繰り返し掲載しない。内部情報を削ったことを正式認定・BC対象への昇格と扱わない。

読者が数値や図を理解するための説明は、簡潔な「紙面の見方」一か所にまとめる。欠測や予想未掲載など、そのレースを読むうえで必要な状態は短く明示する。記者名を各見出しで繰り返さない。

表現整理で凍結原稿・予想JSON・印・買い目・根拠・数値を変更しない。旧号の無差別書換えはしない。

的中速報には当てた記者名と区分（本線・逆張り・舟券ナビ）を併記する。両記者が当てた場合は双方を表示する。参照原稿のない記者は「未確認」とし、不的中に置き換えない。記者タブを切り替えても的中の帰属は変えない。

結果速報は、記者切替・場検索、結果進捗と本線1着/2連単/3連単、記者別平買い収支、高配当的中、全レース/的中一覧/結果待ち、区分別成績の順に読める構成とする。高配当的中は全国一覧の上。全国一覧は12Rずつ表示し、掲載券とR別収支は折りたたむ。成績は本線・逆張り・ナビ・全区分の4区分に投資/払戻/収支/回収率を表示する。

3連単は区分内の同一券を除外し、区分間は独立購入。2連単は各区分の1・2着射影を重複除外して各100円。見送り・予想なし・結果待ちは分母から除く。払戻未取得の的中Rを収支の0円にせず保留し、集計可能R数を示す。返還未確認の速報値はその旨を「集計の見方」へ一度だけ記載する。
