# 公開紙面に出す情報

読者に表示するのは発行日・場/R・締切、記者名、予想と支持順、買い目、展開・攻撃/受益の解説、コース成績・母数・対象期間・欠測表示、STスリット、結果・払戻・的中記者・成績。

SHA、Gate0、検収、正式BCの認定状態、凍結時刻、入力/凍結原本への管理リンク、取得失敗人数・内部処理や再出力の説明は `data/issue-source-YYYY-MM-DD.json` と共通台帳で保持し、公開紙面には出さない。新しい管理用ブロックを作る場合は `data-public-audit` を付ける。

`assets/reader-presentation.js` が公開読者向けの共通境界。`index.html` は表示前に原本HTMLを投影し、記者切替・後読み解説の追加にも同じ規則を適用する。原本アーカイブ、入力、買い目、SHA・集計・時刻の検証は変更しない。`render_ochap_frozen.mjs` も同じ境界を使い、取得日一覧の管理用ドロワーを出力しない。

締切後の参考予想、未掲載、読込失敗など読者の判断に必要な状態は短く表示する。欠測・0走・母数・全国/当地/SGG1区分を隠して、取得済みや0%と見せてはいけない。成績の分母、100円あたりの払戻、重複券の集計方法は必要な見方として保持する。

検証：`node scripts/test_reader_presentation.js`。実際の直近3号、後読み解説、色付き買い目・支持順・スクリプト/圧縮原本の保持を検証する。既存のCIでも実行する。
