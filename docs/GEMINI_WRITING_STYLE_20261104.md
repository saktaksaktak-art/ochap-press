# Gemi兄への共有プロンプト｜艇番カラー・予想の書き方

Gemi兄へ。卓也の最新指示です。
「予想目に艇番カラーを用いてほしい。書き方はおちゃっぴー側が好みなので、Gemi兄もおちゃっぴーの書き方と揃えてほしい。」

今後新規に作成する予想原稿と公開表示へ、以下を適用してください。

1. 買い目の1〜6を、1白・2黒・3赤・4青・5黄・6緑で表示してください。背景色と読める文字色を組み合わせ、色だけでなく数字も残してください。本線・逆張り・舟券ナビ・ダイジェスト・結果画面の掲載券、今後のHTML/PDFで統一します。数値データ・JSONは従来どおり数字/文字列のまま保持し、表示時に色を付けます。

2. 書き方の見本は、お茶P記者の現在の公開原稿です。
https://saktaksaktak-art.github.io/ochap-press/?date=2026-11-04
各Rは、結論が先に分かる短い文で書いてください。例えば「①の先マイを軸。③はコースSTと攻め残りで相手筆頭。②は内差し残りを比較。」のように、誰がどう勝つか・なぜ相手を上に取るかを具体的に伝えます。この例の艇・評価・結論を別Rへ転用しないでください。

3. 表示・文章の基本順序を揃えてください。
   - ◎○▲△と予想決まり手、短い結論・比較理由
   - 本線3点／独立した逆張り／舟券ナビ（補完対象と不成立条件）
   - ①逃げ成立／①逃げ崩壊の独立した展開説明
   - 頭候補ごとの2着・3着比較。図は折りたたみ等で読みやすく配置
既存の出走表・コース別データ・ST詳細は保持し、情報を落とす指示ではありません。

4. 前置き、同じ結論の反復、過剰な見出し、定型の注意書きを増やさず、艇番・コース・ST・機力・壁・攻め筋と比較理由を短く具体的に書いてください。見送り・欠測・少標本など読者の判断に必要な状態は簡潔に示してください。SHA・凍結時刻・受渡し経緯・正式BC認定等の内部情報は裏側の記録へ残し、各Rの紙面へ反復掲載しないでください。

5. 揃えるのは文章の構成・読みやすさ・艇番カラー・買い目の見せ方です。Gemi兄の独立した予想判断・展開・印・券・根拠を、お茶Pと同じにする指示ではありません。お茶Pの当日予想を読んで自分の判断を変更せず、凍結済みの原本・既発行号も改変しないでください。新規原稿は独立推論後にこの書式へ整え、原本の保存・公開の工程を維持してください。

おちゃっぴー側では共通表示に艇番カラーを実装します。Gemi兄側で巨大HTMLや別の公開経路を重複生成せず、従来どおり予想JSONと必要な受渡し資料を保存してください。受領と、次回以降にこの書き方を適用することを共通マスター第0章で返信してください。取得ジョブ・スケジュール・正式BCは変更不要です。
