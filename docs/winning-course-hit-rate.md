# 1着の実コース別・◎的中率 — 公開スコアカード契約（2026-11-01）

お茶P新聞 / 比較画面の「1〜6コース別・◎1着的中率」に用いる仕様。

## 定義

- **実コース**: レース確定後、公式進入表で1C〜6Cの順に並んだ艇番。枠番や艇番1〜6と同一視しない。
- **各コース分母**: そのコースに進入した艇が実際に1着となり、同一M0入力と両記者の締切前原稿・公式結果・実進入を確認できた共通レースの件数。
- **お茶P記者の分子**: 当該分母内で、お茶P記者の◎（main_pick）が1着艇番と一致する件数。
- **Gemi兄記者の分子**: 同じ分母で、Gemi兄記者の◎が1着艇番と一致する件数。
- 的中率 = 分子 ÷ 分母 × 100。分母0件は「—（0R）」とし、0％と表示しない。
- 公式実進入が未取得・未検証ならコース別分母から除外する。結果の着順が判明していても艇番からコースを推測しない。
- 期間は既存の前日・週間7日・月間30日・年間365日。会場/級別等の既存絞り込みと併用できる。
- 「1コースからの1着」などの条件フィルターは、**そのコースから実際に勝ったレース**の比較。全コース表は全レース選択時に6行を示す。

## 公開データ JSON（public-performance.json）の追加可能フィールド

```json
{
  "official_entry_verified": true,
  "official_entry_source_ref": "official source identifier (non-secret)",
  "actual_entry_order": [3, 5, 1, 2, 4, 6]
}
```

- `actual_entry_order[0]` = 1コース艇番、`[5]` = 6コース艇番。
- 例の進入では5号艇が2コース、1号艇が3コース。実際の1着艇番が5なら勝者の実コースは2Cとなる。
- 実進入が不明の場合、3フィールドとも**付けない**。`official_entry_verified: false` と数値を添えて公開しない。
- 3フィールドがあれば既存スキーマ検証で6艇完全順列、公式参照、検証済み状態を検査する。
- 両記者の予想は締切前・同一入力SHA・非事後・同じ公式結果で突合したものだけを採用。
- 公開ファイルに内部BC集計や内部Google Drive参照、個人秘密情報を混入しない。

## 二種類の「コース別的中」の区別

今回実装したのは **実際の勝者が走ったコース別** の1着指名精度。
「記者が1コース頭を推奨したとき何％当たるか」という**予想時のコース別的中率**は別指標であり、予想進入の凍結履歴を要する。両者を同じ母数として混合しない。
